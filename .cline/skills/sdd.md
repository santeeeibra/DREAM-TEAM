# Skill: Spec-Driven Development (SDD)
* **Comando:** `/plan-task`
* **Comando:** `/implement-task`

## Instrucciones de Ejecución
1. Antes de codificar lógica compleja (como `c.pendientes` o cruces de temporadas), ejecuta `/plan-task` para generar una especificación técnica en base al estándar Arc42.
2. Divide las tareas críticas de forma granular empleando principios SOLID y Arquitectura Limpia.
3. El subagente "Judge" (Juez) validará de forma aislada que el código generado no duplique funciones de simulación y respete los contratos de datos del harness headless.
