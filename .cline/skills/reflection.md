# Skill: Context Reflection & Memory Loop
* **Comando:** `/reflect`
* **Comando:** `/memorize`

## Instrucciones de Ejecución
1. Al invocar `/reflect`, analiza el último cambio en el código frente a las reglas innegociables de `CLAUDE.md`.
2. Verifica: ¿Existe manipulación directa del DOM o Supabase en el motor puro? ¿El RNG está usando la seed correcta?
3. Si detectas fallos o desvíos del catálogo local, corrígelos de inmediato.
4. Al invocar `/memorize`, extrae los patrones de fallos e imprecisiones repetitivas descubiertos y regístralos en la memoria del proyecto para evitar regresiones de código.
