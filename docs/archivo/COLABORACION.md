# Colaborando con Claude — Manual de Operaciones

¡Hola, Claude! Acá van algunas pautas para que nuestro trabajo juntos en este proyecto sea lo más eficiente y fructífero posible:

## Antes de empezar
1. Leé siempre el `CLAUDE.md` primero. Es tu mapa del proyecto. 
2. Chequeá las reglas en `.clinerules/` para saber qué se espera de vos.
3. Medí tus tokens al principio y al final de cada sesión. Buscamos mejoras continuas.

## Flujo de trabajo
1. Para bugs puntuales o cambios en un archivo, usá Cline/Cursor. Pasame un brief claro.
2. Para refactors grandes o features nuevas, usá Claude Code. Pero primero planificamos acá.
3. Para planificación, diseño y preguntas, este chat es tu lugar. Pensemos juntos antes de codear.

## Comunicación
1. Si algo no está claro, ¡preguntá! No hay preguntas tontas.
2. Si ves un problema o una mejora, decímelo. Valoramos mucho tu perspectiva.
3. Explicame siempre tu razonamiento. Quiero aprender de vos.

## Código
1. Antes de escribir código, asegurate de entender bien el problema y mi expectativa. 
2. Buscá siempre la solución más simple que pueda funcionar.
3. Priorizá código legible y mantenible sobre optimizaciones prematuras.
4. No te olvides de las reglas de arquitectura en `CLAUDE.md`.

## Testing
1. Nuestro harness headless es la fuente de verdad. Si pasa el harness, ¡vamos bien!
2. No mergees código sin pasar por el harness primero.
3. Si encontrás un bug, escribí un test que lo reproduzca antes de arreglarlo.

## Recursos
1. Si te trabás con algo, no dudes en pedir recursos adicionales (docs, ejemplos, contexto).
2. Avisame si necesitás acceso a algún sistema o herramienta adicional.
3. ¡Tu éxito es mi éxito! Estoy acá para darte todo lo que necesites.

¡Gracias por ser parte de este proyecto! Estoy muy entusiasmado de ver lo que podemos lograr juntos. 

No dudes en sugerir mejoras a este manual. ¡Vos también podés enseñarme a mí cómo trabajar mejor con vos!

Santi
